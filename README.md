# 🚀 Karo Pitch

A modern, high-converting, and premium-feeling landing page for **Karo Pitch**, a startup discovery and funding platform. Designed with a 'Fintech-meets-Startup-Ecosystem' aesthetic, featuring sleek glassmorphism effects, smooth scroll animations, and a fully responsive mobile-first design.

![Karo Pitch](https://via.placeholder.com/1200x630.png?text=Karo+Pitch+-+Startup+Discovery+%26+Funding)

## ✨ Features

- **Modern & Premium UI/UX**: Distinctive dark/white theme aesthetics tailored for the fintech and startup ecosystem.
- **Smooth Animations**: Powered by `framer-motion` for dynamic, engaging scroll and hover effects.
- **Glassmorphism Elements**: Sleek frosted-glass design touches that highlight the platform's key features.
- **Mobile-First & Fully Responsive**: A flawless experience across mobile, tablet, and desktop devices.
- **Rich Iconography**: Clean, consistent, and beautiful icons provided by `lucide-react`.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) (with [TypeScript](https://www.typescriptlang.org/))
- **Build Tool**: [Vite 8](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🏃 Getting Started

### Prerequisites

You need to have **Node.js** (v18 or higher) and npm (or yarn/pnpm) installed on your system.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Shaurya705/karo_pitch.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd karo_pitch
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```
   *(or `yarn` / `pnpm install` depending on your package manager)*

### Development Server

Start the Vite development server with Hot Module Replacement (HMR):

```bash
npm run dev
```

Open your browser and navigate to **[http://localhost:5173](http://localhost:5173)** to see the app in action.

### Building for Production

Compile the project into a production-ready bundle:

```bash
npm run build
```

This will generate the optimized static assets in the `dist` directory, which can be deployed to Vercel, Netlify, or your preferred hosting provider.
